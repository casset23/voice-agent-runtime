# Co-Agent Dashboard Frontend

以 React 为主技术栈开发的 Co-Agent 仪表板前端网页。

## 开发指南

开发时建议优先使用 PNPM

安装所有依赖：

```shell
pnpm i
```

开启开发服务器：

```shell
pnpm dev
```

构建网站：

```shell
pnpm build
```

预览构建产物：

```shell
pnpm preview
```

构建 Docker 镜像：

```shell
docker build -t co-agent-dashboard-frontend .
```
