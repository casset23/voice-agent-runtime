# 源码公开版整理说明

本版来自用户指定的已有智能音箱项目源码，包含原 Rust Gateway、Python LLM Runner、NestJS 资源中心、React 管理台和四个工具服务。此前仓库首页上的单进程独立演示已经从当前版本替换，旧提交保留历史。

公开整理保留原服务实现，并进行以下修改：

- 模型与天气服务中的硬编码 Key 改为读取环境变量。
- 内网模型地址改为本地回环地址，并提供配置变量。
- 公司设备请求头统一改为 X-Device-ID，示例平台名称改为 demo-speaker-v1。
- 公司域名、镜像路径和品牌图片改为通用路径及本仓库图标。
- 移除资源中心 SQL 参数调试输出，避免本地模型凭据被日志打印。
- 修正已失效的默认脚手架单元测试，新增针对原服务的本地检查。
- 重写根 README；部署模板保留为参考，没有触发部署。

排除：原始公司图片、与项目无关的练习文件、AI 工作说明和简历/面试包装草稿、历史性能宣传材料、旧自动化工作流，以及密钥配置、数据库、运行日志、依赖目录和构建产物。

没有将原源码改造成另一套业务实现。原接口的鉴权占位、并发计数和工具分发方式仍按实际实现说明，不虚构生产成熟度。

Python 测试替身只用于隔离模型和资源中心网络，不随运行服务启用；运行时仍走原 OpenAI-compatible Function Calling 路径。

本地原始目录不修改。公开版完整文件清单和源文件哈希对照保存在本地交付记录中，不包含原始凭据。

## 文档与可靠性补充

在源码脱敏整理之后，本轮重写文档并加入实际管理界面截图；截图数据由隔离临时数据库中的合成配置提供。
LLM SDK 配置刷新增加候选注册表构建失败回滚、空闲客户端回收、在途调用延迟关闭及进程关闭时释放，使用 6 个独立异步测试覆盖。该部分是公开整理后的代码改进，原本地源码未改动。
