# 个人展示版设计

目标：用一条可运行、可测试的链路展示智能音箱文字指令的后端治理。

这是 2026-10-24 独立整理的新演示实现，未复制原公司项目源码、部署资源、业务配置或数据。它不代表原公司系统的完整功能或线上成果。

选择：Python + FastAPI 单进程实现 Gateway、LLM Runner、Tool Registry 三个逻辑层，降低复现门槛。与多服务版本相比，当前版本不展示跨服务网络和 Rust 网关性能；需要实测后再做服务拆分。

流程：Bearer 鉴权 → 生成 Request ID → 获取并发配额 → 规划单次工具调用 → 校验白名单和参数 → 执行 → 释放配额。模型不直接获得代码执行、文件访问或外部工具地址。

边界：文本作为 ASR 上游输入；离线规则模型作为默认演示；真实模型走 OpenAI-compatible JSON API；音量工具明确返回 simulated=true。没有麦克风采集、唤醒词、TTS、真实音箱驱动或多轮 ReAct。

验证顺序：先定义接口、鉴权、参数边界、超时释放、并发饱和和恢复测试，确认缺少实现时失败，再实现并运行同一组测试。真实模型连接需另行配置密钥验证。
